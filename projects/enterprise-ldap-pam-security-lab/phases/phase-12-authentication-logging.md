# Phase 12 — Authentication Logging

Identify local evidence for SSH successes/failures, PAM events, SSSD diagnostics and sudo activity. Build a timeline using source IP, user, login, process, sudo and sensitive resource access.

## Deliverables

- Architecture/design evidence for Phase 12.
- Commands/configuration evidence with secrets redacted.
- Verification result and expected-vs-observed outcome.
- Troubleshooting notes for failures.
- Security reasoning: what control is being enforced and why.
- Where applicable, NCA ECC evidence reference.
