TARGET CONTROLS

Lab security policy

Password policy

Minimum 12 characters, 90-day maximum age, history 5.

Failed authentication

5 failures, 15-minute failure window, 15-minute unlock window.

SSH authorization

Direct root login disabled; approved LDAP groups only.

These are documented lab targets. Exact module behavior must be validated on the deployed Ubuntu/OpenLDAP/SSSD versions before production use.
